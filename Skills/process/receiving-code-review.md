# receiving-code-review

**Type:** Process
**Plugin:** superpowers

## What it is
Handle code-review feedback with technical rigor — verify suggestions before implementing,
don't perform blind agreement or reject reflexively.

## How we used it on this project
The post-review cleanup commits are the trace of this skill, e.g.
`0005755 chore(filesystem-mcp): post-review cleanup`. The browser PR chain (#2–#4) is
itself a series of review-driven follow-up fixes after the initial feature merge.
