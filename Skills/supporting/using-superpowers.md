# using-superpowers

**Type:** Supporting (meta-skill, runs at conversation start)
**Plugin:** superpowers

## What it is
The entry-point skill that establishes how to find and use all other skills — "if there's
even a 1% chance a skill applies, invoke it." Sets the process-skills-first priority order
(brainstorming/debugging before implementation skills).

## How we used it on this project
The gate in front of everything else. It's why every feature started with brainstorming +
a spec instead of jumping straight to code, and why the workflow loop was consistent across
all six subsystems.
