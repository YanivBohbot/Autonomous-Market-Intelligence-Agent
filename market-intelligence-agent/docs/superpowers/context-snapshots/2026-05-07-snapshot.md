## Architectural decisions captured

| Decision | Rationale | Commit / file |
|---|---|---|
| Migrate from `interrupt_before=["tools"]` to dynamic `interrupt()` + `Command(resume)` | Per-tool decisions, batch atomicity, modern LangGraph idiom | `15bca90` / `app/agent/graph.py` |
| `READ_ONLY_TOOLS` allowlist bypasses HITL | Quote/news lookups don't deserve human gate; reduces friction | `c1d2efe` / `app/agent/tools/__init__.py` |
| Atomic batch HITL: any reject cancels all calls | Avoid partial-execution bugs from batched `tool_calls` | `3c97308` / `approval_node` |
| `StructuredTool.from_function` for multi-arg tools, legacy `Tool` only for single-string-arg | Pydantic schema derivation from type hints | `a854615` / `yfinance_client.py` |
| Yahoo Finance integrated as second MCP stdio server (parallel to CRM) | Reuses proven pattern; no shared base class until 3rd MCP server | `3164ea8` / `yfinance_client.py` |
| `SqliteSaver` checkpointer, not `MemorySaver` | Sessions survive restarts | `c8443c0` / `app/agent/memory/checkpointer.py` |
| API split into routers (health, approve, stream) | Clear surface area, easier to test | `c8443c0` / `app/api/routers/` |
| `SYSTEM_PROMPT` extracted to `app/agent/prompts/system.py`, in English | Prompt growing too large for inline; portfolio in English | `551a75f` |
